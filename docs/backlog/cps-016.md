# [CPS-016] The subtitle shows the file's full path

**Status**: Open
**Priority**: Medium
**Component**: `src/CmdPal.Extension.Shortcuts/ShortcutsCommandsProvider.cs`, `README.md`
**Related**: [CPS-002b](cps-002b.md) (title and subtitle of a catalogue entry)

**Summary**:
As a user of Command Palette, I want each entry's subtitle to show the file's full path, so that I can tell `wsl-manager.ps1` from its `wsl-manager.bat` wrapper and see which file starts.

**Description**:
The title is the file name without its extension, and the subtitle is the folder. A script and
its `.bat` wrapper in the same folder show the same title and the same subtitle; only the icon
tells them apart. With the full path as the subtitle, the extension is visible while the title
stays short.

Raised on 2026-11-17.

**Scope Decisions**:
- **Subtitle, not title** (the author, 2026-11-17): the title stays the name without extension.
- **Wrappers stay listed** (the author, 2026-11-17): a `.bat` next to a `.ps1` of the same name is not hidden; the author deletes wrappers that are not needed.

**Acceptance Criteria**:
- [ ] The subtitle of every catalogue entry is its full path, extension included
- [ ] The title is unchanged: the file name without its extension

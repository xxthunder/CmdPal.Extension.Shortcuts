# [CPS-014] A file added in a linked subfolder appears without a restart

**Status**: Open
**Priority**: Low
**Component**: `src/FoldersCatalog/CatalogWatcher.cs`, `src/FoldersCatalog/Catalog.cs`
**Related**: [CPS-002d](cps-002d.md) (live updates, which leave linked subfolders out), [CPS-002a](cps-002a.md) (links below a `\**` pattern are followed)

**Summary**:
As a user who links folders into `~\shortcuts`, I want a script saved in a linked subfolder to show up without a restart, as it does in a plain subfolder.

**Description**:
The catalogue follows junctions and symbolic links below a `\**` pattern (CPS-002a). The
watcher of CPS-002d watches each pattern folder with `IncludeSubdirectories`; on Windows
`FileSystemWatcher` (`ReadDirectoryChangesW`) does not descend into reparse points. A file
added inside a linked subfolder therefore appears only after another change in the watched
tree or a restart of Command Palette.

A way to close it: `Catalog` reports the real folders it walked, and the watcher adds one
watcher per link target below a pattern.

Raised on 2026-11-15, from the final review of CPS-002d.

**Acceptance Criteria**:
- [ ] A file created in a linked subfolder below a `\**` pattern appears in the main search without a restart
- [ ] A file deleted there disappears without a restart

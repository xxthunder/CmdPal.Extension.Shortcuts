# [CPS-017] Folders can be excluded in the settings

**Status**: Open
**Priority**: Medium
**Component**: `src/FoldersCatalog/`, `src/CmdPal.Extension.Shortcuts/Helpers/SettingsManager.cs`, `README.md`
**Related**: [CPS-002c](cps-002c.md) (folders and extensions as settings), [CPS-006](cps-006.md) (folders whose names start with a dot are left out), [CPS-002d](cps-002d.md) (the watcher)

**Summary**:
As a user of Command Palette, I want to name folders the extension leaves out, so that library folders such as `~\shortcuts\lib` do not fill the main search with files I never start.

**Description**:
A `\**` pattern catalogues every subfolder except those whose names start with a dot. Folders
that hold libraries, such as `%USERPROFILE%\shortcuts\lib`, show their scripts in the main
search although they are dot-sourced, not started.

A second setting, "Excluded folders", next to "Folders": one folder per line, with the same
syntax (environment variables and `~` expanded, `\**` for its subfolders). A file in an
excluded folder is not catalogued.

Raised on 2026-11-17.

**Scope Decisions**:
- **A setting of its own** (the author, 2026-11-17): "Excluded folders" is a second field, not
  exclusion lines (`!...`) inside "Folders": clearer for someone who installs from the Store.

**Acceptance Criteria**:
- [ ] The settings have "Excluded folders", one folder per line, empty by default
- [ ] A file in an excluded folder does not appear in the main search
- [ ] An excluded folder with `\**` also leaves out its subfolders; without it, only the folder's own files
- [ ] Changing the excluded folders takes effect without a new build
- [ ] The README describes the setting
